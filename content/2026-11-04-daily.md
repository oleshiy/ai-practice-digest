## Опыт компаний

### [Airbnb: дообученный классификатор сравнялся с крупными моделями при сотой части стоимости](https://airbnb.tech/ai-ml/frontier-quality-at-1-of-the-cost-a-production-benchmark-of-llm-classifiers/)

Airbnb дообучила Gemma4-E2B на сотнях тысяч примеров нарушений правил оплаты: на 10 тысячах отложенных примеров, взвешенных по их доле в рабочем трафике, F1 — баланс точности и полноты — выросла с 0,563 до 0,902, при медианной задержке 35 мс. Модели сравнивали с общей инструкцией примерно в 400 слов; для моделей с числовой оценкой выбирали лучший порог решения, а у API с готовым вердиктом считали F1 этого ответа. Крупные API-модели давали сопоставимое качество примерно за 900 мс; при тысячах запросов в минуту расчёт обслуживания на одной RTX Pro 6000 был примерно в сто раз дешевле передовых API по публичным ценам октября 2026. Расчёт не включает обучение; дешёвые API были дороже GPU примерно в пять раз, а ниже 15–30 запросов в минуту передовые API обходились дешевле выделенного GPU.
