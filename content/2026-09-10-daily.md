# AI за 10 сентября · обновлённый выпуск

## Полезные материалы

**AWS: как найти первую ошибку в диалоге агента.** Метод AEM проверяет правильность и полноту каждого ответа и вызова инструмента, затем отделяет исходную ошибку от её последствий. Нужны эталонные ответы и действия; пример AWS объясняет метод, но не показывает измеренный результат его применения в реальном сервисе. [Методика](https://aws.amazon.com/blogs/machine-learning/agent-evaluation-metric-for-multi-turn-conversations/)

**NVIDIA: как обслуживать больше запросов на том же оборудовании.** Разбор NIM для Nemotron 3 Ultra объединяет повторное использование контекста, группировку запросов и предложение нескольких следующих токенов для проверки моделью. Выигрыш зависит от оборудования, нагрузки и допустимой задержки: авторы советуют проверять настройки на собственном потоке запросов. [Технический разбор](https://developer.nvidia.com/blog/how-full-stack-nim-optimizations-deliver-2-5x-more-users-on-nemotron-3-ultra/)

## Опыт компаний

**Shopify: перенос Shop на отдельные приложения для iOS и Android.** Переход с общего кода React Native занял 12 недель от прототипа до публикации. Агенты переносили функции по проверенным планам и сверяли поведение работающих приложений, инженеры отвечали за архитектуру и качество. Этот срок относится к конкретной миграции и не обещает такого же результата в другом проекте. [Разбор команды](https://shopify.engineering/shop-app-migration)

**Microsoft: специализированные агенты для сетевых операций.** Один агент обновляет диагностику, другой помогает передавать заявки исполнителям, третий сообщает о сбоях. Действия с оборудованием доступны уполномоченным инженерам, внешнюю заявку одобряет человек. Объединение этих агентов в сквозной рабочий процесс компания пока описывает как следующий этап. [Опыт Microsoft](https://www.microsoft.com/insidetrack/blog/from-alerts-to-action-how-ai-agents-are-reshaping-network-operations-at-microsoft/)

**Credit Genie: документация обновляется вслед за кодом.** OpenWiki ночью проверяет изменения репозиториев и готовит обновления документации. Их автоматически принимают, затем перестраивают портал для сотрудников и агентов программирования. Так устроен процесс в кейсе поставщика; автоматическое обновление само по себе не гарантирует точности документации. [Кейс](https://www.langchain.com/blog/how-credit-genie-uses-openwiki-to-keep-codebase-knowledge-fresh-searchable-and-automated)

## Новости

**OpenAI открыла основу Codex через Agents API.** Сервис управляет долгими сессиями, контекстом и распределением работы между агентами. Для выполнения кода можно выбрать среду OpenAI, партнёра или свою инфраструктуру. Пока API доступен в публичной бета-версии. [Анонс](https://openai.com/index/introducing-the-agents-api/)

**Atlassian: от задачи Jira до проверки кода человеком.** Новые циклы работы выбирают хорошо описанные свободные задачи, передают агенту выполнение и тестирование, затем открывают изменения кода для проверки человеком. Эти функции пока в закрытом раннем доступе. [Пост Atlassian](https://www.atlassian.com/blog/jira/governed-agent-loops)

**Cognition выпустила модель для программирования SWE‑2.** При обучении модель получает награду за решение задачи и штраф за стоимость выполнения: так настраивают несколько уровней тщательности работы. SWE‑2 доступна в Devin Desktop и CLI; сравнения качества и цены приводит сам разработчик. [Анонс и методика](https://cognition.com/blog/swe-2)

**Data agent работает с данными компании в ChatGPT Work.** Агент учитывает корпоративные определения показателей и ограничения доступа к таблицам, строкам и столбцам, а результаты собирает в обновляемые интерактивные отчёты. В анонсе есть отзывы клиентов, но нет независимой оценки точности. [Анонс](https://openai.com/index/put-data-to-work/)

**GPT‑Live‑1 вышла в API для голосовых агентов.** Модель одновременно слушает и говорит, а сложные рассуждения и вызовы инструментов передаёт другой модели. Заявленные $0,05 за минуту относятся только к голосовому слою, не ко всей системе. [Анонс](https://openai.com/index/introducing-gpt-live-1-in-the-api/)
