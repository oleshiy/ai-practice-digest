# Практики ИИ

Русские редакционные дайджесты: опыт компаний, исследования, стоимость, проверка качества и ограничения.

Сайт: https://oleshiy.github.io/ai-practice-digest/

В репозитории находятся только готовые выпуски и статический сайт. Пересказы сохраняют ссылки на источники; утверждения компаний не выдаются за независимые измерения.

## Сборка

Требуется Python 3.11 или новее, без внешних зависимостей:

```sh
python3 build.py
python3 check.py
```

Результат находится в `_site/`. GitHub Actions автоматически собирает и публикует его в GitHub Pages после изменений в `main`.

## Новый выпуск

Добавьте готовый Markdown в `content/` и его описание в `editions.json`. Сохраните даты окна, оговорки, исходные ссылки и полный список находок. Выполните сборку и проверку перед отправкой изменений.

Поддерживаемая разметка выпусков: заголовки, абзацы, нумерованные и маркированные списки, ссылки, выделение и встроенный код. Не добавляйте HTML или исполняемый код в тексты выпусков.
