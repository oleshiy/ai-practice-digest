# Практики ИИ

Русские редакционные дайджесты: опыт компаний, исследования, стоимость, проверка качества и ограничения.

Сайт: https://oleshiy.github.io/ai-practice-digest/

В репозитории находятся готовые компактные выпуски, отдельный архив находок и статический сайт. Пересказы сохраняют ссылки на источники; утверждения компаний не выдаются за независимые измерения.

## Сборка

Для сборки нужен Python 3.11 или новее, для проверки поиска — Node.js. Внешних библиотек нет:

```sh
python3 build.py
python3 check.py
node test_archive.js
node test_releases.js
python3 test_publisher.py
```

Результат находится в `_site/`. GitHub Actions автоматически собирает и публикует его в GitHub Pages после изменений в `main`.

## Новый выпуск

Добавьте один готовый Markdown в `content/`. Перед текстом обязательны только `date`, `type` (`daily`, `last10`, `last30` или `top30`) и `title`; имя имеет вид `YYYY-MM-DD-латинский-slug.md`. Заголовок `#` в тексте должен совпадать с `title`. По желанию можно добавить `label`, `subtitle`, `window`, `count` и параметры существующего формата; без них сборщик подставит безопасные значения. Сохраните даты окна, оговорки, исходные ссылки и полный список только вошедших в выпуск находок там, где он обязателен. Дайджест не заменяет архив: последний доступен на `findings.html`, с поиском, фильтрами по источнику и периоду и постраничным просмотром. Сборщик сам создаёт страницу выпуска, полный каталог и главную; `index.html`, `archive.html` и отдельный manifest вручную не редактируются.

```md
---
date: 2026-09-11
type: daily
title: AI за 11 сентября
---

# AI за 11 сентября
```

Поддерживаемая разметка выпусков: заголовки, абзацы, нумерованные и маркированные списки, ссылки, выделение и встроенный код. Не добавляйте HTML или исполняемый код в тексты выпусков. Проверка отклоняет неверную дату, тип, metadata или имя файла; одноимённый slug невозможен, потому что он берётся из уникального имени файла.

Архив в `content/findings.json` содержит прежние принятые пересказы; этот статус явно указан на странице. Новые версии заменяют их только после редакционной проверки. Поиск работает в браузере, без внешнего сервиса и передачи запросов.
